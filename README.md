### 🤖 sim2real-vla · Closed-Loop VLA Post-Training
Closed-loop vision-language-action post-training in a domain-randomized MuJoCo Franka tabletop sim. SigLIP plus Qwen2.5-0.5B, with discrete and flow-matching action heads, FSDP2 training on a single node with 4x A100s, and a decoupled GRPO actor-learner setup for low-latency inference.

| Stack | Focus |
| --- | --- |
| Python, PyTorch, MuJoCo, SigLIP, Qwen2.5-0.5B, FSDP2, DeepSpeed ZeRO-3 | VLA post-training, behavior cloning, GRPO-style RL, CUDA-graph inference |

### 🎓 ProjectSchola · Socratic AI Tutor for Claude Code
A Socratic AI tutor for Claude Code. Learn any topic, or teach from your own PDFs, textbooks, docs and videos, with verified citations, quizzes, spaced review and live Obsidian notes. Local-first.

| Stack | Focus |
| --- | --- |
| Python, Claude Code, Obsidian | Socratic tutoring, verified citations, spaced repetition, local-first learning |

### 🧪 chemcrow-orchestrator · Local ChemCrow Agent
A ChemCrow fork with a local Ollama-backed reasoning LLM, a custom-tool scaffold, and a Streamlit UI for chemistry reasoning without sending work to a hosted model.

| Stack | Focus |
| --- | --- |
| Python, LangChain, Ollama, RDKit, Streamlit | Local LLM agents, chemistry tools, AI for science |

### ⚛️ OPV-Chemist · RL Framework for Organic Photovoltaic Discovery
Extended CycleChemist into a hardened, DFT-validated RL framework for organic photovoltaic discovery, combining generative transformers, structural plausibility gating, and TD-DFTB oracle validation.

| Stack | Focus |
| --- | --- |
| Python, PyTorch, Transformers, RDKit, RL | Generative molecular design, RL for materials discovery, OPV |

### 👁️ QueryScope · Local Visual Q and A
Local visual question answering. Upload an image, ask a question, and get an answer from a vision-language model running entirely on your machine via Ollama. No cloud calls, no API keys.

| Stack | Focus |
| --- | --- |
| TypeScript, React, FastAPI, Python, Ollama, Qwen3-VL | Vision-language models, local-first AI, VQA |
